# mercurius-memory

**English** | [Русский](README.ru.md)

Long-term memory for an agent: a fact store with versions, trust, provenance and entities, lexical retrieval with a relevance gate and holographic reduced representations (HRR), and background consolidation. Follows the principles of hermes-plugin-holographic and hermes-dreaming.

Part of [Mercurius](https://github.com/opencck/mercurius) — an autonomous personal agent. The package does not depend on the Mercurius application and can be used on its own.

**Status:** planned, no code yet.

**Stack:** PHP 8.2+, AMPHP v3, PostgreSQL.
